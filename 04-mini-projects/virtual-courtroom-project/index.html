About the Project

Civic Jury Simulator is a citizen-participation interactive simulation platform
that allows users to experience judicial procedures through AI-powered virtual cases.

재판 진행 과정

1. 사건 생성

운영자가 AI 기반 가상 사건을 생성합니다.

2. 공소 투표

공소 제기 또는 공소 중지 투표가 진행됩니다.

3. 증거 제출

참여자는 증거와 논리를 업로드합니다.

4. 최후 변론

가장 설득력 있는 변론이 투표됩니다.

5. 판결

운영자가 최종 판결을 내립니다.

투표 시스템
