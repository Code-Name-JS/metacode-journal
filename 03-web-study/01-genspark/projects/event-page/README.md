> 상위 문서: [Genspark 웹사이트 구현 및 개발 학습 프로젝트](../../README.md)

---

## 프로젝트 개요

이 프로젝트는 **젠스파크(Genspark)**를 통해 제공받은 웹 디자인 시안(v1.0)을 실습용으로 구현한 미니 프로젝트입니다. 본 문서는 **v1.0 시안 기반 이벤트 프로모션 페이지(2026 가을 감사 페스티벌)**의 README입니다.

화면에 보이는 모든 문구 · 경품 · 일정 · FAQ를 **JSON 파일에 모아 두고, JavaScript가 읽어서 화면을 그리는 구조**입니다. HTML은 뼈대만 담당하고, 내용은 데이터에서 주입합니다.

---

## 프로젝트(v1.0)의 목적

- **데이터(JSON)와 화면(HTML)을 분리**해서, 코드를 건드리지 않고 문구만 바꾸는 구조 익히기
- TypeScript로 **JSON 데이터의 타입(`interface`)을 정의**하고 컴파일하기
- `setInterval` **카운트다운**, `IntersectionObserver` **스크롤 등장 효과** 구현하기
- 응모 폼 **유효성 검사 → 성공 모달** 흐름 만들기

## 주요 기능

### v1.0

| 기능 | 설명 |
|------|------|
| JSON 기반 렌더링 | `data/event.json`의 `hero` · `stats` · `prizes` · `schedule` · `faq` · `form` · `footer`를 읽어 각 섹션 생성 |
| 데이터 폴백 | `file://`로 열어 `fetch`가 막히면 `src/main.ts`에 내장된 `FALLBACK_DATA` 사용 |
| 카운트다운 | `hero.endDate`까지 남은 시간을 1초마다 갱신, 종료 후 마감 문구 표시 |
| 스크롤 등장 효과 | `IntersectionObserver`로 섹션이 보일 때 나타나는 애니메이션 |
| 헤더 | 스크롤 위치에 따라 헤더 스타일 변경, 내비게이션 링크 렌더링 |
| 일정 타임라인 · FAQ 아코디언 | 일정 목록과 질문 펼치기 / 접기 |
| 응모 폼 검사 | 이름 · 연락처 등 필드별 검사, 휴대폰 번호 자동 하이픈 |
| 응모 완료 모달 | 0.6초 지연 후 응모 번호와 함께 성공 모달 표시 (데모 · 서버 전송 없음) |

## 기본 파일 구조

```
event-page/
├── README.md
├── img/                  ← 시안 캡처 (추가 예정)
└── v1.0/
    ├── README.md         ← v1.0 상세 설명 (빌드 · 커스터마이즈 방법)
    ├── index.html        ← 마크업 (구조만 담당, 문구는 JS가 JSON에서 주입)
    ├── style.css         ← 반응형 + 다크 히어로 + 타임라인 · 아코디언 · 모달
    ├── src/main.ts       ← TypeScript 원본 (타입 정의 · 렌더링 · 카운트다운 · 폼 검사)
    ├── js/main.js        ← tsc 컴파일 결과 (브라우저가 실제로 실행하는 파일)
    ├── data/event.json   ← 모든 문구 · 경품 · 일정 · FAQ 데이터
    └── tsconfig.json
```

---

## 기술 스택

- **HTML5**: 시맨틱 섹션 구조, 폼 요소, 모달 접근성 속성
- **CSS3**: CSS 변수(`:root`), 타임라인 · 아코디언 · 모달 스타일, 반응형
- **TypeScript**: JSON 데이터 `interface` 정의, `tsc` 컴파일
- **JavaScript (ES2020)**: `fetch`, `setInterval`, `IntersectionObserver`, 이벤트 처리

## 실행 방법

TypeScript를 수정했다면 `v1.0` 폴더에서 먼저 컴파일합니다.

```bash
npx tsc
```

```
event-page/v1.0/index.html
```

> `data/event.json`을 실제로 읽으려면 **Live Server 같은 로컬 서버**로 열어야 합니다. `file://`로 열면 내장 폴백 데이터가 대신 사용되고, 콘솔에 안내 로그가 남습니다.
