How it works

3단계면 끝나는 참여

평균 소요 시간 30초. 회원이 아니어도 이메일만 있으면 참여할 수 있습니다.

  1. 01

    참여 정보 입력

    이름과 이메일, 휴대폰 번호만 입력하면 응모가 완료됩니다.

  2. 02

    쿠폰 즉시 수령

    완료 화면에서 쿠폰 코드 4종을 한 번에 확인하고 복사할 수 있습니다.

  3. 03

    구매하고 응모권 적립

    결제 금액 1만원당 응모권 1장이 자동 적립되어 럭키 드로우에 참여됩니다.
