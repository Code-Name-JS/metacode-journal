## 프로젝트 개요

이 프로젝트는 직접 작성한 **화면 설계도(Login-page v1.1)** 를 바탕으로 로그인 화면을 구현하는 실습용 미니 프로젝트입니다. 본 문서는 `v1.0` 폴더의 README이며, **HTML · CSS · JavaScript** 만으로 제작합니다.

> 설계도 버전(v1.1)과 구현 폴더 버전(v1.0)은 별개입니다. 설계도는 v1.1까지 다듬어졌고, 이를 처음 코드로 옮기는 구현이 v1.0입니다.

---

## 프로젝트의 목적

로그인 화면은 요소 수는 적지만 **입력 → 검사 → 결과 표시** 흐름이 모두 들어 있는 기본 화면입니다. 본 프로젝트는 다음 목표를 달성하고자 합니다.

- 화면 설계도의 수치(px, 굵기, 색)를 CSS로 정확히 옮기는 연습
- 카드 레이아웃을 화면 정중앙에 배치하는 방법 익히기
- `:focus`, `:hover` 같은 상태 선택자로 사용자 반응 표현하기
- JavaScript로 입력값을 검사하고 에러 문구를 보여주는 흐름 연결하기

## HTML · CSS · JS 연결 지점 (계획)

구현할 때 세 언어가 만나는 지점입니다. 이름(id · class)은 직접 정하되, **세 파일에서 철자가 정확히 같아야** 합니다.

| 연결 | HTML | CSS | JavaScript |
|------|------|-----|------------|
| [연결①] 입력칸 | input의 `id` | input 크기 · `:focus` 스타일 | `getElementById`로 값 읽기 |
| [연결②] 에러 문구 | 에러 문구 요소의 `id` / `class` | 기본 숨김 + 빨간 글씨 | 요소를 찾아 보이기 / 숨기기 |
| [연결③] 표시 상태 | 상태 클래스(예: 보이기용 클래스) | 상태 클래스가 붙었을 때의 스타일 | `classList.add` / `remove` |
| [연결④] 로그인 버튼 | 버튼의 `id` | `:hover` 색 변화 | `addEventListener('click', …)` |

## 설계 확인 메모

구현 전에 설계도에서 한 번 더 정해야 할 부분입니다.

- **아이디 vs 이메일**: 설계도 화면의 placeholder는 `아이디를 입력해 주세요.`인데, 명세와 에러 문구는 **이메일** 기준입니다. 하나로 통일이 필요합니다.
- **input type**: 명세의 `type=box`는 HTML에 없는 값입니다. 이메일은 `type="email"`, 비밀번호는 `type="password"` 중 무엇을 쓸지 정합니다.
- **"올바른 비밀번호"의 기준**: 몇 글자 이상인지 등 검사 규칙을 정해야 JavaScript로 구현할 수 있습니다.
- **카드 높이 600px 고정**: 에러 문구가 나타나면 내용이 늘어나므로, 넘치지 않는지 확인합니다.

## 기술 스택

- **HTML5**: `form`, `input`, `button`, `placeholder`
