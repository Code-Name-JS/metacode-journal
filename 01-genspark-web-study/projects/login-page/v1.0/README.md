# MyApp – 로그인 페이지 시안

## 프로젝트 개요
모던하고 세련된 디자인의 로그인 페이지 시안입니다.  
순수 HTML · CSS · JavaScript로 구현되었으며 별도 빌드 도구 없이 브라우저에서 바로 실행됩니다.

---

## ✅ 완성된 기능

| 기능 | 설명 |
|------|------|
| 이메일 / 비밀번호 로그인 폼 | 실시간 유효성 검사 (blur & submit) |
| 비밀번호 표시/숨기기 | 아이콘 토글 버튼 |
| 로그인 상태 유지 | localStorage로 이메일 저장 |
| 소셜 로그인 버튼 | Google / GitHub (UI만 구현, 토스트 안내) |
| 로딩 스피너 | 제출 중 버튼 로딩 상태 표시 |
| 토스트 메시지 | 성공 / 실패 / 안내 세 가지 타입 |
| 카드 흔들기 애니메이션 | 로그인 실패 시 shake 효과 |
| 반응형 레이아웃 | 모바일(480px↓) 대응 |
| 접근성 | aria-label, aria-live, role="alert" 등 적용 |
| 배경 블롭 애니메이션 | 부드러운 float 효과의 컬러 블롭 |

---

## 📁 파일 구조

```
index.html        ← 메인 페이지
style.css         ← 모든 스타일 (CSS 변수, 애니메이션 포함)
main.js           ← 인터랙션 & 유효성 검사 로직
README.md
```

## 🎨 디자인 특징

- **컬러 팔레트**: 보라(#6c63ff) 주색 + 핑크(#ff6584) 포인트 + 그린(#34d399) 보조
- **타이포그래피**: Inter (Google Fonts)
- **애니메이션**: 카드 진입, 브랜드 아이콘 팝, 블롭 플로트, 토스트 슬라이드
- **그림자 & 블러**: backdrop-filter + layered box-shadow로 유리 효과
