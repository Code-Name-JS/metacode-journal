# MyApp - 로그인 페이지 시안(2가지 버전)

## 프로젝트 개요
두 가지 스타일의 모던 로그인 페이지 시안입니다.
순수 HTML·CSS·JavaScript로 구현되었으며 별도 빌드 도구 없이 바로 실행됩니다.

---

## 파일 구조

```
v1.0/
    index.html           ← 버전 1 센터 카드 · 라이트 테마
    style.css            ← 버전 1 스타일
    main.js              ← 버전 1 인터랙션

v2.0/
    index.html        ← 버전 2 좌우 분할 · 다크 패널
    showcase.html        ← 두 버전 비교 선택 페이지 (메인)
    style.css            ← 버전 2 스타일
    main.js              ← 버전 2 인터랙션
README.md
```

## 버전 비교

| 항목 | Version 1 | Version 2 |
|------|-----------|-----------|
| **레이아웃** | 화면 중앙 단일 카드 | 좌우 50:50 분할 |
| **테마** | 라이트 (흰 배경 + 보라 포인트) | 다크 좌 패널 + 화이트 우 |
| **배경 효과** | 컬러 블롭 플로트 애니메이션 | 공전 오빗 + 펄스 애니메이션 |
| **회원가입** | 미포함 | 탭 전환으로 통합 |
| **소셜 로그인** | Google, GitHub | Google, 카카오, 네이버 |
| **비밀번호 강도** | ✗ | ✅ 4단계 강도 바 |
| **카운터 애니메이션** | ✗ | ✅ 스탯 숫자 카운트업 |

## 공통 기능

- 실시간 + submit 유효성 검사 (이메일 형식, 필수값)
- 비밀번호 표시/숨기기 토글
- 로그인 상태 유지(localStorage)
- 로딩 스피너(제출 시 1.3s 시뮬레이션)
- 성공/실패/안내 알림(자동 4초 후 사라짐)
- 폼 흔들기 애니메이션(로그인 실패 시)
- 반응형 레이아웃(모바일 720px ↓ 대응)
- 웹 접근성(aria-label, aria-live, role 등)
