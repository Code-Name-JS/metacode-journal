# Genspark 웹사이트 부분 구현 제작 프로젝트
Genspark 프로그램에서 개발된 웹 학습 프로젝트 모음집입니다. 이 프로젝트 폴더는 사용자인 JS가 웹 개발을 배우고 연습할 수 있도록 만들어졌습니다. 각 버전마다 발전 과정을 기록하여 다양한 디자인 시안을 통해 하나의 웹사이트 구축해 나가는 것을 목표로 삼고 있습니다.

---

## 프로젝트 학습 목표
이 프로젝트는 단순한 웹사이트 제작을 넘어,
HTML → CSS → JavaScript → 서버/API → 데이터베이스
로 이어지는 웹 개발의 구조를 이해하기 위한 기반으로 만들어지는 것입니다.

특히 프론트엔드 개발 과정에서 자주 사용하는 DOM 조작, 이벤트 처리, 상태 관리, 동적 렌더링, CRUD UI를 직접 구현하는 데 초점을 맞추어 공부합니다.

---

## 프로젝트 구조
projects에는 앞으로 bulletin-board-page, login-join-page, login-page 이외의 다양한 page 프로젝트 파일을 생성할 예정입니다.

프로젝트의 특징적인 구조에는 v1.0 / v2.0 / v3.0과 같은 Genspark를 통해 만들어진 새로운 디자인의 시안을 공부한 프로젝트 버전들 입니다. v1.1 / v1.2 또는 v2.1 / v2.2 등 첫번째 소수점 단위로 숫자가 올라가면 기존 Genspark 디자인 시안을 v1.0, v2.0, ··· 에서 참고하여 사용자 JS가 새로운 디자인의 시안 프로젝트를 선보이는 구조물을 갖추고 있습니다.

```plaintext
01-genspark-web-study/
│
├── projects/
│   ├── bulletin-board·login-join·login-page/
│   │   ├── v1.0/
│   │   │   ├── index.html
│   │   │   ├── style.css
│   │   │   ├── main.js
│   │   │   └── README.md
│   │   ├── v1.1/
│   │   │   ├── index.html
│   │   │   ├── style.css
│   │   │   ├── main.js
│   │   │   └── README.md
│   │   └── v2.0/
│   │       ├── ...
│   │       └── README.md
│   └── ...
│
└── README.md
```

## 프로젝트 개요
- **목적**: 웹 개발 공부와 실습을 위한 프로젝트 모음집입니다.
- **핵심 기술**: HTML, CSS, JavaScript
- **버전 관리**: 각 프로젝트는 v1.0, v2.0, v3.0과 같은 버전의 폴더로 정리됩니다.
- **폴더 관리**: 각 프로젝트는 v1.1, v2.1, v3.1과 같이 첫번째 소수점 자리의 숫자가 올라가면 새로운 디자인 폴더로 정리됩니다.
- **폴더 및 디자인 자원**: 각 버전의 폴더에는 다양한 디자인 시안의 Genspark 자원이 포함되어 있습니다.

---

## 다양한 페이지의 버전들

| 버전 | 주요 특징 | 개발 접근법 |
| --- | --- | --- |
| **v1.0, v2.0** | 기본 HTML/CSS/JS 로그인 페이지 | 보편적인 디자인의 정적인 구조 |
| **v1.1, v2.1** | JS가 만든 맞춤 디자인(색상 및 이미지 수정) | 기존 디자인의 변화된 구조 |

---

## 실행 방법 및 커스터 마이징
1. 원하는 버전 폴더로 이동하세요.
- 예시: projects/login-page/v1.0
2. 브라우저에서 index.html을 엽니다.
3. 필요에 따라 style.css와 main.js를 수정해 커스터마이징하세요.

---

## 폴더 사용 참고 사항 및 확장
- 각 버전의 README.md에서는 디자인 하이라이트, 기술적 개선 사항을 확인할 수 있습니다.
- Code-name-js가 직접 디자인한 버전(v1.1, ···)은 원본으로 간주되며, 색상 팔레트와 이미지 자산은 별도로 관리됩니다. 
- v2.0부터 v3.0 이상 버전까지 페이지의 다양한 변형이 개발될 예정입니다.
