# 학습 노트 정오표 (2026-10-16 기준)

학습자의 Notion 노트에서 발견한 오류 목록이다. 학습자에게는 **위치와 힌트를 먼저** 알려 주고, "정답"은 학습자가 요청할 때만 보여 준다. 학습자가 이미 고쳤을 수 있으니 노트를 다시 읽어 확인한 뒤 언급한다.

## 프로그래밍의 기본 요소

| 위치 | 힌트 | 정답 |
|---|---|---|
| "인수 우선 평가 대 정상 순서 평가"의 전개 코드 세 번째 줄 | 곱셈을 나타내는 기호가 맞는지 보기 | `(5 + 1) & (5 + 1)` → `(5 + 1) * (5 + 1)` |
| "조건부 표현식과 술어"의 첫 `abs` | 본문 설명("크거나 같으면")과 코드의 비교 연산자가 같은지 보기 | 책은 `x >= 0 ? x : -x` |
| "복합 함수"의 `function f(x) { return x * x; }` 블록 | 바로 뒤에 같은 이름 `f`가 또 선언됨. 어느 쪽이 책의 `f`인지 | 책의 `f`는 `f(a)` 버전 하나뿐. 앞 블록은 불필요 |

## 함수와 과정

| 위치 | 힌트 | 정답 |
|---|---|---|
| "선형 재귀와 반복"의 `plus` 결론 "두 식은 모두 문법 오류를 발생한다" | 콘솔에서 `inc`, `dec`를 선언하고 `plus(4, 5)`를 실제로 실행해 보기 | 문법 오류 아님. 둘 다 `9`. 첫 번째는 `inc(...)`가 지연되므로 재귀적 과정, 두 번째는 `a`, `b`만으로 상태가 서술되므로 반복적 과정 (연습문제 1.9) |
| 같은 곳의 `plus(4, 5)` 추적 설명 ("8이 나옵니다 … 8이 9가 됩니다") | 치환 모형으로 한 줄씩 전개해 보기 | `plus(4,5)` → `inc(plus(3,5))` → `inc(inc(plus(2,5)))` → … → `inc(inc(inc(inc(5))))` → `9` |
| "트리 재귀"의 피보나치 수열 나열 | 각 수가 앞의 두 수의 합인지 하나씩 더해 보기 | `0, 1, 1, 2, 3, 5, 8, 13, 21, …` |
| "약수 찾기"의 `find_divisor` | 매개변수 이름과 본문에서 쓰는 이름의 철자 비교 | `divides(text_divisor, n)` → `divides(test_divisor, n)` (그대로면 `ReferenceError`) |
| "페르마 판정법"의 `expmod` 마지막 줄 | 세미콜론 자리와 `m` 뒤의 글자 보기 | `% ml` → `% m;` |
| "페르마 판정법"의 `fermat_test` | 원시 함수 이름 철자 | `math_foolr` → `math_floor` (브라우저에서는 `Math.floor`) |
| "거듭제곱"의 첫 `expt` | 다른 함수들과 비교 연산자가 같은지 | `n == 0` → `n === 0` (결과는 같지만 책과 일관성) |

## 고차 함수를 이용한 추상의 정식화

| 위치 | 힌트 | 정답 |
|---|---|---|
| "람다 표현식"의 `pi_sum` | 인수 사이 구분 기호 보기 | `x => x + 4;` → `x => x + 4,` (그대로면 `SyntaxError`) |
| `sum` 설명 "구간의 상계 a와 하계 b" | `a > b`일 때 멈춘다면 어느 쪽이 시작값인지 | `a`가 하계(시작), `b`가 상계(끝) |
| 정적분 근사 공식의 첫 항 | 다른 항들은 모두 `f(...)`로 감싸져 있음 | `(a + dx/2)` → `f(a + dx/2)` |
