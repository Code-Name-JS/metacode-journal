# 베스트픽(BestPick) — 베스트 상품 페이지

판매량·리뷰·평점 기반의 **베스트 상품 랭킹 페이지** 데모입니다.
HTML / CSS / TypeScript / JavaScript 로 작성되었으며, 번들러 없이 브라우저에서 바로 실행됩니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 마크업 (헤더 · 히어로 · 툴바 · 상품 그리드 · 장바구니 드로어) |
| `style.css` | 디자인 토큰(CSS 변수) 기반 스타일시트 + 반응형(4/3/2열) |
| `main.ts` | **TypeScript 원본** — 인터페이스/타입 정의, 목 데이터, 렌더링 및 이벤트 로직 |
| `main.js` | `main.ts`를 `npx tsc`로 컴파일한 결과물 (브라우저 실행용) |
| `tsconfig.json` | 컴파일 설정 (`strict: true`) |

## 실행 방법

```bash
# 1) TypeScript → JavaScript 컴파일
npx tsc

# 2) 로컬 서버로 열기 (권장)
npx serve .
# 또는 그냥 index.html 을 브라우저로 열어도 동작합니다.
```

## 주요 기능

- **랭킹 배지** — 1~3위는 금·은·동 메달 컬러, 4위 이하는 기본 배지
- **카테고리 탭** — 전체 / 패션 / 뷰티 / 디지털 / 식품 / 생활 / 스포츠
- **정렬** — 인기순(판매량) · 가격순(낮은 가격) · 리뷰순(리뷰 수)
- **찜하기** — 카드 우측 상단 하트 토글, 헤더에서 찜한 상품만 보기
- **장바구니** — 담기/빼기 토글, 드로어에서 수량 조절·삭제·합계 계산
- **검색** — 상품명·브랜드·태그 실시간 필터
- **더 보기** — 8개씩 점진적 로딩
- **상태 저장** — `localStorage`에 찜/장바구니 유지
- **이미지 폴백** — 이미지 로드 실패 시 SVG 플레이스홀더로 자동 대체

## 참고

- 상품 데이터는 `main.ts`의 `PRODUCTS` 배열에 정의된 **목(mock) 데이터**입니다.
- 이미지는 `picsum.photos`의 고정 시드를 사용합니다.
