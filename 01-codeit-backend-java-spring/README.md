# Codeit Backend Java & Spring

> 코드잇에서 AWS 활용 Spring 백엔드 개발자 실무 부트캠프 과정을 통해 Java 기반 백엔드 개발의 기본기부터 Spring Boot, 데이터베이스, API, 보안, 테스트, AWS 클라우드 배포 및 대용량 트래픽 처리까지 단계적으로 학습하는 과정을 기록한 폴더입니다.

* Java 기반 객체지향 프로그래밍 역량 강화
* 알고리즘과 자료 구조에 대한 기본기 학습
* Spring 및 Spring Boot의 핵심 개념 이해
* RESTful API 설계 및 구현
* 데이터베이스 설계와 Spring JPA 활용
* 클라우드 환경에서의 애플리케이션 배포 경험
* TDD와 테스트를 통한 서비스 안정성 학습
* Spring Security를 활용한 웹 애플리케이션 보안 학습
* 대용량 트래픽을 고려한 백엔드 구조 이해
* 백엔드 네트워크 구조 및 동작 원리 이해
* 단계별 Spring 프로젝트를 통한 실전 개발 경험

> **Learn → Build → Test → Deploy → Improve**
